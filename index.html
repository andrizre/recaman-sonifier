The Recamán sequence

Start at 0. For step n, try to move n steps backward: a(n) = a(n−1) − n — but only if the result is positive (> 0) and has never appeared before. Otherwise move forward instead: a(n) = a(n−1) + n.

The first terms are: 0, 1, 3, 6, 2, 7, 13, 20, 12, 21, 11, 22, 10, 23, 9, 24, 8, 25, 43, 62…

It is an open problem whether every positive integer eventually appears. Here the sequence is drawn as semicircular arcs (as in the famous Numberphile visual) and each value is mapped to a musical pitch, so its jagged, repeating-but-never-quite structure can be heard.
